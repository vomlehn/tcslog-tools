# tcslog-tools 0.3.0

Built against tcslog 0.6.0, so the tools read logs in its stored format
1.1, whose `VariableTsRc` record count is 48 bits, as well as format 1.0.
Logs written by tcslog 0.4.3 and earlier are still refused: use 0.1.8 for
those. A minor release, because the tools' library half now depends on
tcslog 0.6.

`tcslog-dump --rec-size <bytes>` sets the largest payload it reads without
truncating, and by default it now reads 64 KiB rather than 256 bytes.

Packages are attached: a `.deb` and an RPM that install both tools under
`/opt/tcs`, built for x86_64 Linux.

Requires `tcslog` 0.6, whose stored format 1.1 widens a `VariableTsRc`
record count to 48 bits; it still reads format 1.0.

### Added

- `tcslog-dump --rec-size <bytes>` sets the largest payload read without
  truncation.
- `make lint-packages` checks the packages with lintian and rpmlint, and
  their shell scripts with shellcheck, and fails on any finding not
  overridden with its reason.
- The .deb carries `/usr/share/doc/tcslog-tools/copyright`, in Debian's
  machine-readable format, `changelog.Debian.gz` and lintian overrides,
  and the RPM a `%changelog` and a `Group`, all made from the version as
  the package is built.
- The .deb carries `DEBIAN/md5sums`, the MD5 of every file it installs,
  which `dpkg --verify` and debsums check an installed package against.

### Changed

- `tcslog-dump` reads a record's payload into 64 KiB by default, as
  tcslog's record iterator does, rather than 256 bytes.
