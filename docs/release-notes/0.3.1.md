# tcslog-tools 0.3.1

Built against tcslog 0.7, which split its code generator into a package of
its own, tcslog-gen, and left the library and the stored formats it reads
as 0.6 had them, so these tools read the same logs as 0.3.0: stored format
1.1, whose `VariableTsRc` record count is 48 bits, and format 1.0. A patch
release, because nothing the tools do or export has changed.

Packages are attached: a `.deb` and an RPM that install both tools under
`/opt/tcs`, built for x86_64 Linux.

Requires `tcslog` 0.7.

### Changed

- Built against `tcslog` 0.7 rather than 0.6, which the checkout beside
  this one no longer is.
- Installing and packaging use the packaging scripts the TCS projects
  share, from a checkout of tcs-helpers beside this one; `make install`
  builds the packages and installs the one the system takes with its own
  installer; and the packaging targets are tcs-helpers' `packaging.mk`:
  see CHANGELOG.md.
